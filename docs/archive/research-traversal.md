# Research: agent traversal & retrieval over a personal knowledge graph

*Historical (2026-06-11) — findings folded into specs v4; kept for rationale only.*

2026-06-11. Method: 5 parallel search threads (tool-surface design; memory products; graph-RAG papers; production agent retrieval; personal-scale mechanics); ~30 primary sources; 12 load-bearing claims adversarially re-verified against primaries (11 confirmed, 1 corrected). Vendor-run benchmarks flagged as such.

## 1. What works (evidence + adoption)

### Representation: how the store is shown to the model

- **Typed tools beat raw SQL as the primary surface.** On realistic enterprise schemas, raw-SQL agents solve 21.3% (Spider 2.0 v2, Mar 2025, arxiv.org/abs/2411.07763); BIRD top entry 81.95% vs 92.96% human (bird-bench.github.io, Sep 2025). Schema hallucination is documented (TA-SQL, arxiv 2405.15307). The reference Postgres MCP server (raw `query` tool) was deprecated Jul 2025 after a read-only-bypass SQL injection (Datadog Security Labs); raw `execute_sql` was the vector in the Supabase "lethal trifecta" leak (simonwillison.net/2025/Jul/6/supabase-mcp-lethal-trifecta/). Surviving servers (crystaldba/postgres-mcp ~2.9k stars) wrap SQL with typed discovery tools + DB-role-level read-only enforcement, never prompt-level.
- **Summary-first with drill-down pointers is explicitly validated.** Anthropic's context-engineering guidance (Sep 2025, anthropic.com/engineering/effective-context-engineering-for-ai-agents): maintain "lightweight identifiers (file paths, stored queries, web links)" and load at runtime — named "progressive disclosure"; context is a finite "attention budget." Agent Skills (Oct 2025) is the same three-tier pattern. Tool responses: `response_format: concise|detailed` (concise ≈ 1/3 tokens), 25,000-token default cap in Claude Code, and **semantic identifiers over bare UUIDs** — resolving meaningful names "significantly improves Claude's precision... by reducing hallucinations" (anthropic.com/engineering/writing-tools-for-agents, Sep 2025).
- **The winning retrieval unit = atomic fact/episode + timestamps + provenance pointer.** LoCoMo (arxiv 2402.17753, Feb 2024): retrieving atomic "observations" with dialog provenance scores 41.4 F1 vs 22.4 base, while "session summaries... do not significantly improve performance." LongMemEval (ICLR 2025, arxiv 2410.10813): round-level units, fact-augmented index keys (~+5% QA accuracy), time-aware query expansion (+7–11% recall on temporal questions). Zep/Graphiti (27.3k stars, active Jun 2026) stores per edge: NL fact + relation + **four timestamps** (event valid/invalid, ingestion created/expired) + pointers to source episodes (arxiv 2501.13956, Jan 2025).
- **Staleness is handled by invalidation/supersedence, not deletion.** Graphiti: contradicted edges get `t_invalid` set, history stays queryable. Mem0 (~41k stars, $24M raised Oct 2025, AWS Agent SDK): ADD/UPDATE/DELETE/NOOP reconciliation at write time (arxiv 2504.19413).
- **Citations cut source hallucination.** Anthropic Citations API (Jan 2025): +15% recall accuracy vs prompted citing; customer Endex: source hallucinations 10%→0% (anthropic.com/news/introducing-citations, vendor-reported).
- **Small packets beat big ones.** Mem0's ~1.8k-token packets beat 26k full-context on LoCoMo; Zep: 1.6k vs 115k tokens, 2.58s vs 28.9s, +18.5% accuracy (vendor numbers, contested between vendors). Context degrades with length across 18 frontier models even on trivial tasks ("Context Rot," Chroma, Jul 2025, research.trychroma.com/context-rot).

### Traversal: how agents navigate

- **Production code agents converged on agentic iterative search (grep→read→refine), no embedding index.** Claude Code: "agentic search out-performed RAG" (Boris Cherny, HN, Feb 2025); early versions used RAG + local vector DB, dropped for "security, privacy, staleness, and reliability" (Cherny, X, Feb 2026). Same move: Sourcegraph Cody dropped embeddings (Feb 2024), Cline never indexed (May 2025), Aider uses tree-sitter repo-map ranked by personalized PageRank, no embeddings (aider.chat, Oct 2023).
- **The quantified counterpoint is hybrid, not embeddings-only.** Cursor (Nov 2025, cursor.com/blog/semsearch): semantic search +12.5% avg accuracy (6.5–23.5% by model), but their agent "makes heavy use of grep as well" and the **combination** wins; gains concentrate on codebases ≥1,000 files (+2.6% retention). LocAgent (ACL 2025, arxiv 2503.09089): agentic graph traversal 94.2% file-level Acc@5 vs ~76.6% for one-shot embedding retrieval on SWE-bench localization.
- **Deep-research systems train/structure interleaved search→read→refine.** Anthropic multi-agent research system (Jun 2025): "start wide, then narrow," subagents as filters returning condensed findings; multi-agent ≈ 15x chat tokens. OpenAI Deep Research (Feb 2025): end-to-end RL on iterative browsing.
- **Production graph systems budget expansion tightly: 1–3 hops, seeded by hybrid search, then rerank.** Graphiti: cosine+BM25 seeds a BFS hardcoded to 1–3 hops (issue #772, patched but default depth 3), center-node distance + recency rerankers, **no LLM at query time**. LightRAG expands one-hop neighbors only (arxiv 2410.05779). Nobody ships unbounded graph walks.
- **Personal-memory ranking is a weighted SUM: recency + importance + relevance** (all weights 1; recency = exponential decay 0.995 per hour since last retrieval) — Generative Agents §4.1 (arxiv 2304.03442). A sum, not a product: old-but-important items survive.
- **At 1e3–1e5 rows, exact search is the whole stack.** pgvector exact scan: ~36ms @10k rows (Neon), 30–80ms @50k (Instaclustr) — no ANN index needed. BM25 is a strong zero-shot baseline (BEIR, arxiv 2104.08663). Under ~200k tokens total, Anthropic says skip RAG and inline everything (anthropic.com/news/contextual-retrieval, Sep 2024). When both are needed: hybrid + RRF (Supabase pattern, rrf_k=50); contextualized BM25+embeddings+rerank cuts retrieval failure 5.7%→1.9% (same post).
- **Filesystem + standard tools beat bespoke memory APIs.** Letta (Aug 2025, letta.com/blog/benchmarking-ai-agent-memory): a plain filesystem agent on gpt-4o-mini scores 74.0% on LoCoMo, above Mem0's reported best 68.5% — tools in the training distribution (open/grep/search) outperform invented ones.

## 2. What failed, and why

- **Raw SQL as the agent's primary interface** — 21–36% on realistic schemas (Spider 2.0 SOTA 2025), schema hallucination, injection incidents; survives only as a role-level-read-only escape hatch behind typed tools.
- **Upfront exhaustive LLM graph summarization** (GraphRAG indexing, arxiv 2404.16130): practitioner cost cliff ($7/32k-word book; "most teams reaching for it shouldn't" — TDS). Microsoft's own LazyGraphRAG (Nov 2024): equal/better quality at **0.1% of GraphRAG's indexing cost** and >700x lower query cost — i.e., ~99.9% of upfront summarization was waste. GraphRAG has 33.7k stars but heavy 2025–26 "beyond the hype" pushback.
- **Entity-only triple graphs** — HippoRAG 1 stripped context; HippoRAG 2 (ICML 2025, arxiv 2502.14802) had to add passage nodes + query-to-triple matching (+12.5% recall@5 vs NER-to-node). Lesson: keep raw text reachable from the graph.
- **Graphs for personal conversational memory buy little**: Mem0g adds +1.56 points over non-graph Mem0 on LoCoMo (arxiv 2504.19413). PPR-style traversal pays off on corpus-scale multi-hop QA, not at personal scale.
- **Session-level summaries as retrieval units** — high recall, no QA gain (LoCoMo). Summaries are for orientation, not retrieval.
- **Paraphrase-at-write without provenance accumulates hallucinations**: memory systems "generate and accumulate hallucinations during the extraction and updating stages" which propagate to QA (HaluMem, arxiv 2511.03506, Nov 2025); 40–50% of LLM dialogue summaries contain ≥1 factual inconsistency (TofuEval, NAACL 2024).
- **Iterative full-rewrite of memory/context** — "brevity bias" and "context collapse": monolithic rewrites progressively erode detail; structured incremental delta updates fix it (+10.6% on agent tasks) (ACE, ICLR 2026, arxiv 2510.04618).
- **Hyped-not-adopted**: LangMem taxonomy is influential but the SDK is in maintenance mode (1.5k stars, no releases); A-MEM is research-grade (~1k stars, modest GPT-4o-mini gains). All three vendor LoCoMo scores (Zep 75.1 vs 58.4 vs Mem0 68.5) are mutually contested — treat as marketing-grade (blog.getzep.com rebuttal May 2025; getzep/zep-papers#5).

## 3. Recommendations for claudio

1. **Keep L1 typed functions + MCP as the only write surface; keep free-form reads as SELECT over invoker views** (already spec'd). This is exactly the converged pattern: typed workflow tools + constrained query escape hatch enforced at the DB role, not the prompt. Add 2–3 example invocations to every `COMMENT ON` (Anthropic tool-docs guidance: examples, edge cases, boundaries) and a few sample rows per table in generated SCHEMA.md (schema-in-context mitigates SQL hallucination).
2. **Two-phase retrieval protocol**: deterministic SQL `get_context` packet first (cheap, fresh, no LLM at query time — the Zep result), then **agentic drill-down** (view SELECTs, wiki grep/read, `refs` follow-up) for anything beyond the packet. Do not build a graph-walk engine; cap packet link expansion at 1 hop, let the agent iterate for hop 2+ ("start wide, then narrow").
3. **Make every packet item carry id + event timestamp + source_ref, rendered inline.** Temporal reasoning is the measured weak spot of memory systems (LongMemEval: assistants drop 30%+; time-aware retrieval +7–11%). Age must be visible to the model, not just stored.
4. **Score by weighted sum, not product**: `score = w_r·recency_decay + w_d·dueness + w_i·importance`, exponential decay on recency. A recency×due-ness product zeroes out old-but-critical items; the canonical formula (Generative Agents) is a sum.
5. **Quote-at-write for load-bearing facts.** Paraphrased summaries accumulate errors (HaluMem, TofuEval). Atoms' `detail` should carry short verbatim spans for commitments, dates, amounts, names; the existing `propose(..., quoted)` pattern extends to filing. Rule: before any irreversible/external action, re-ground from `refs` (re-read the source), not from the summary.
6. **Adopt invalidation-over-deletion for facts that flip.** Bi-temporal lite: atoms already have `ts` (event) + `created_at` (ingestion); add `superseded_by`/`invalidated_at` semantics on inferred links and amended facts instead of hard-delete (Graphiti's measurable anti-stale mechanism). Keeps point-in-time queries possible.
7. **No embeddings in v0 is correct — but define the promotion trigger now.** Lexical fails on paraphrase ("dental checkup" vs "dentist appointment" — M2A, arxiv 2602.07624); log `search_people`/`what_happened` misses, and when paraphrase misses show up: exact-scan pgvector over atom summaries (no ANN index below ~50k rows) fused with Postgres FTS via RRF. Atoms are stable units, so embeddings bolt on later without re-architecture.
8. **Tool-response ergonomics**: `response_format concise|detailed` on read functions, pagination + token caps with sensible defaults (Claude Code uses 25k), and never return a bare UUID — always pair with name/slug (UUID-only responses measurably degrade precision).
9. **Wiki gardener edits by delta, never full-page regeneration** (ACE context collapse). Patch sections, append cited Highlights; full rewrites only via proposal.
10. **Keep packets small**: default budget ~2–4k tokens (Mem0 1.8k and Anthropic top-20≈4k are the measured optima; context rot beyond). Rollup paths-not-contents (already spec'd) is the right call — that's just-in-time retrieval.

## 4. What this changes in the current design

**Validated, keep as-is:**
- ≤500-char summary atoms + `{source,locator,tool}` refs = LoCoMo's winning "observation" unit (41.4 vs 22.4 F1) + Anthropic progressive-disclosure guidance. The tier 0/1/2 ladder is the literature's consensus shape.
- Boundary rule ("DB stores what agents query; wiki stores what agents read") — session/page summaries don't retrieve well but orient well; exactly LoCoMo's split.
- Pure-SQL `get_context` v0 (no LLM at query time) = Zep's production architecture; deterministic, ~10x faster, fewer tokens.
- Lint-parsed wiki, no `document_links` mirror = LazyGraphRAG lesson (defer derived structure until a real query needs it) + the staleness argument that killed code-embedding indexes (Cody, Cline, Cherny).
- Episode-level atomization (never per-message) — granularity between session (too coarse, proven) and per-message (atom explosion); fact-dense summaries serve as LongMemEval-style "fact-augmented keys."
- No embeddings v0 — at 1e3–1e4 items, FTS + aliases + structured filters is defensible; see trigger in rec 7.

**Change:**
- `get_context` ordering: recency×due-ness **product → weighted sum** with exponential recency decay (rec 4).
- Packet items must render event timestamps + age inline, not only ids (rec 3).
- Add verbatim-quote discipline to filing (`detail` spans) + a re-ground-before-acting rule for workflows (rec 5).
- Links/amendments: add supersedence (`invalidated_at`/`superseded_by`) instead of hard-delete for inferred edges; audit alone loses queryable history (rec 6).
- L1 read functions: add `response_format`, pagination, token caps; pair every UUID with a human-readable name in responses (rec 8).
- `COMMENT ON` should include example calls; SCHEMA.md should include sample rows (rec 1).
- Wiki gardener procedure: explicitly delta-edit, prohibit full-page regeneration (rec 9).
- Write down the embeddings promotion trigger + design (exact pgvector + RRF) in questions-queue so v1 isn't a re-architecture (rec 7).
